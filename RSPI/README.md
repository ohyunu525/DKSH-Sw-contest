# Wi-Fi TCP 송수신 시작하기

Python 3 기본 라이브러리만 사용합니다. 별도 웹 서버나 클라우드 계정은 필요 없습니다.
노트북이 연결을 기다리고 라즈베리파이가 연결을 시작합니다.

## 1. 노트북에서 수신 프로그램 실행

이 폴더에서 터미널을 열고 실행합니다.

```powershell
python receiver.py
```

`Listening on 0.0.0.0:5000`이면 수신 대기 상태입니다.
Windows에서 `python` 명령을 사용할 수 없지만 Python이 설치되어 있다면 `py receiver.py`를 시도합니다.

## 2. 같은 노트북에서 먼저 확인

별도 터미널에서 실행합니다. 이 단계에는 라즈베리파이가 필요 없습니다.

```powershell
python sender.py 127.0.0.1 --text hello
```

수신 터미널에 `RECEIVED`, 전송 터미널에 `ACK`가 표시되면 로컬 송수신 성공입니다.

## 3. 실제 Wi-Fi 연결

노트북과 라즈베리파이를 같은 LAN에 연결합니다. 노트북에서 `ipconfig`를 실행해 실제 연결된 Wi-Fi 어댑터의 IPv4 주소를 확인합니다.
라즈베리파이에 sender.py를 옮긴 후 실행합니다. 아래 IP는 예시이므로 노트북 주소로 바꿉니다.

```bash
python3 sender.py 192.168.0.15
```

입력한 문자가 노트북으로 전송되고 같은 연결로 수신 확인이 돌아옵니다.
`/quit`으로 송신을 종료하고, 노트북에서는 Ctrl+C로 수신을 종료합니다.
수신 프로그램은 120초 동안 데이터가 없으면 해당 연결을 종료합니다. 다시 sender.py를 실행하면 됩니다.

## 연결 문제 확인

- 로컬 시험도 실패: 수신 프로그램 실행 여부와 포트를 확인합니다.
- 로컬은 성공하고 라즈베리파이만 실패: IP, Windows 방화벽, 공유기의 장치 간 통신 차단 여부를 확인합니다.
- 신뢰하는 개인 네트워크에서 Python의 인바운드 TCP 5000 연결을 허용합니다. 방화벽 전체를 끄지 않습니다.
- 학교·게스트 Wi-Fi는 장치 간 접속을 차단할 수 있습니다.
- 포트 사용 중: 수신과 전송 모두 `--port 5001`을 추가합니다.

## 이 예제의 범위

수신 확인용 텍스트 메시지를 보내는 작은 통신 예제이며 가상 로봇 프로그램은 아닙니다.
`ACK`는 메시지를 받았다는 뜻이고 ML 처리 완료나 로봇 동작 완료를 의미하지 않습니다.
메시지는 UTF-8 JSON 한 줄이며 줄바꿈이 메시지 경계입니다. 최대 크기는 줄바꿈 포함 65,536바이트입니다.
실제 센서 연동 시 sender.py의 `data`에 측정값을 넣을 수 있습니다.
인증·암호화·자동 재연결·ML·모터 제어는 포함하지 않았습니다. 신뢰하는 LAN에서 연결 시험용으로 사용합니다.
