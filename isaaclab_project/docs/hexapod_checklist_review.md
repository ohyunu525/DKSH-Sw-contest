# 헥사포드 Isaac Sim 체크리스트 반영

2026-10-10 제공된 체크리스트를 현재 Onshape CAD6 환경에 대조했다.
참조 문서 SHA-256은
`63dd9679e345dbb8200e991863bc4c7e8644808aef6e73fcddd39a7d1add36a2`이다.
현재 실험 목적은 조립 영점과 제한된 서보 모델에서 고전 wave 보행의 물리적
가능성을 확인하는 것이다. 학습 정책의 관측 계약은
`simulation_only_privileged_state_v1`이며, 실물 배포 가능 정책으로 취급하지 않는다.

## 적용한 설정

- 물리 5 ms, 제어 20 ms는 유지한다. 사전검사의 `--physics_dt`를
  2.5/5/10 ms로 바꿔도 decimation을 조정해 제어 20 ms를 유지한다.
- 지면과 로봇에 같은 물리 재질을 적용한다. 정적·동적 마찰 0.6,
  restitution 0, combine mode average가 기본이며 0.4/0.6/0.8 비교를 지원한다.
- CAD 영점·축·±90도 제한, 18관절, 19강체와 질량은 유지한다.
  body-coxa MG90S 4.8 V, 두 다리 관절 RC920DMG 5 V 설정은 체크리스트의
  MG996R 출발값으로 교체하지 않는다. 기록하는 토크 비율은 각 관절의 현재
  시뮬레이션 출력 상한 대비 비율이며 제조사 연속 정격 대비 비율이 아니다.
- CAD에서 병합된 발끝 좌표를 각 tibia의 `foot_frame` Xform으로 복원한다.
  6개 tibia에 ContactSensor를 활성화하며 센서 데이터는 정책 관측에 넣지 않는다.
- 단순 충돌은 `--simple_collisions` 선택 시 CAD 부품별 STL 경계 상자로
  대체하고 가정한 반지름 5 mm 발 패드를 추가한다. 시각 메시·질량·관성은
  CAD 값을 유지한다. 경계 상자는 원본보다 보수적인 외곽이므로 형상별 결과를
  구분해 보관한다. 패드 중심은 CAD foot 프레임의 로컬 +Z로 5 mm 오프셋한
  가정이며 실측 발바닥 두께나 월드 수직 방향으로 해석하지 않는다.
  기본은 이전 검증에 사용한 convex hull이다.
- 자기 충돌은 기본 off, `--self_collisions`로 켤 수 있다.
- 학습 메타데이터에 관측 계약, 실물 배포 불가 상태, 물리/제어 주기, 재질을
  기록하고 Onshape gait, 서보 사양, payload, 진단 코드도 실행 스냅샷에 포함한다.

## 발끝 프레임과 접촉력 해석

원본 URDF의 6개 foot 링크는 질량 `1e-9 kg`, 관성 0이며 충돌 형상이 없는
좌표 프레임이다. 이 링크에 직접 ContactSensor를 붙이거나 고정 관절 병합만
끄는 방식은 접촉을 측정하지 못하고 불필요한 강체를 만든다. 따라서 병합을
유지하면서 foot 위치/자세를 Xform으로 복원하고, 실제 충돌을 소유하는 tibia의
접촉력을 측정한다. 기록되는 힘에는 tibia에 붙은 다른 충돌 형상의 접촉도
포함될 수 있다. 별도 발바닥 형상에 대한 힘 분리가 필요하면 실제 발 재질과
형상 확정 후 충돌 필터를 추가해야 한다.

Isaac Lab 4.5 ContactSensor의 `net_forces_w`는 법선력 합계이며 접선 마찰력은
포함하지 않는다. 따라서 수평 성분을 마찰력으로 보고 필요 마찰계수
`옆힘/수직힘`을 계산하지 않는다. 현재 슬립은 지면 접촉 중 발끝 평면 속도가
0.01 m/s를 초과하는 상태가 60 ms 이상 연속 유지될 때로 정의한 진단 가정이다.
60 ms는 프레임 수가 아니라 실제 제어 dt로 누적한다. 발끝 속도에는 tibia
중심질량 병진 속도와 회전 속도에 따른 `omega × (foot_position - COM_position)`을
모두 포함한다. 링크 원점과 중심질량의 좌표를 혼용하지 않는다.

## 실행과 기록

```powershell
# 서로 다른 조건의 결과를 별도 이름으로 보관한다.
foreach ($mu in @('0.4', '0.6', '0.8')) {
    .\run_mg90s.ps1 -Mode check -RobotModel cad6 -SpeedProfile velocity -NumEnvs 4 -Friction $mu
}

# 단순 형상 및 물리 간격 비교
.\run_mg90s.ps1 -Mode check -NumEnvs 4 -SimpleCollisions
.\run_mg90s.ps1 -Mode check -NumEnvs 4 -PhysicsDt '0.0025'
.\run_mg90s.ps1 -Mode check -NumEnvs 4 -SelfCollisions
```

각 조건에 JSON 요약과 동일 이름의 JSONL 시계열을 남긴다. 시계열은 제어
주기 20 ms마다 모든 환경의 관절별 출력 토크, 상한 비율, 명령/속도, 자세,
발끝 위치/속도, 접촉 법선력, 슬립과 종료 상태를 저장한다. 요약에는 관절별
최대 토크/비율, 80% 이상 체류 시간(ms), 속도 오차, 첫 낙상까지 거리와
발별 슬립 지속 시간을 추가한다. 이 최대값과 체류 시간은 20 ms 샘플 기준이며
5 ms 하위 단계의 짧은 피크를 전부 포착하는 측정으로 해석하지 않는다.
넘어지지 않은 환경의 낙상까지 거리는 null이다. 자동 리셋의 순간 이동은
누적 보행 거리에서 제외한다.

직접 Python 검사에서 `--root_height`로 몸체 높이 가정을 바꾸거나
`--timeseries`로 로그 경로를 지정할 수 있다. 실험 옵션은 사전검사에만 적용하며
기존 학습/재생에 전달하면 실행기가 오류를 출력한다.

## 후속 실험의 선행 조건

계단 높이 10 mm 간격과 디딤판 280 mm 조건은 다음 지형 실험 기준으로 둔다.
현재 평지 성공 판정은 계단 등반 성공 판정이 아니다. 계단에서는 실제 발바닥,
접촉 분리, 간섭 검사와 지형을 고려한 발 목표 생성이 먼저 필요하다.
서보 지연·백래시·노이즈·질량 무작위화의 실측값이 없으므로 이번 수정으로
하드웨어 특성을 확정하지 않는다. 관절 피드백 없이 명령 각도와 IMU를 쓰는
정책은 별도 관측 계약과 새 학습이 필요하다. 현재 정책은 이 실험용으로 유지한다.
