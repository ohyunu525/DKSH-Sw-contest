# Tibia 말단 지지와 Dynamic Gait 적용 검토

검토일: 2026-10-29. 대상은 Onshape CAD6, 몸체–coxa MG996R 6개와
femur/tibia RC920DMG 12개를 사용하는 직접 관절각 학습 경로다.

## 판단

**말단 지지를 먼저 학습한 뒤 평지에서 빠른 tripod를 비교하는 것은 가능하다.**
다만 현재 하드웨어 가정으로 비행 구간이 있는 달리기나 bipod를 바로 적용할 근거는 부족하다.
무릎을 발처럼 쓰는 현상은 gait 주파수보다 접촉 판정과 자세 비용의 문제를 먼저 해결해야 한다.
말단 지지가 유효 보폭과 지면 여유를 늘릴 수는 있지만, 속도 향상은 재학습 후 같은 조건의
평가로 확인해야 한다. 목표 속도 설정값은 달성 속도가 아니다.

현재 정책은 18개 **절대 목표 관절각**을 직접 출력한다. 기본 gait에 정책 출력을 더하는
구조가 아니므로, CPG나 IK를 출력 뒤에 삽입하면 행동 의미가 달라진다. 이번 접촉 수정과
동적 gait 실험은 독립적으로 검증할 수 있다. 후속 CPG–IK 비교는 별도 task와 새 관측·행동
계약으로 구현하고, 현재 직접각 정책도 같은 지형과 서보 제한에서 비교하는 편이 타당하다.

## 현재 구조에서 확인한 제약

| 항목 | 저장소 기준 | 적용 시 의미 |
|---|---|---|
| 물리/정책 주기 | 물리 200 Hz, decimation 4 → 정책 50 Hz | 고속 접촉은 물리 substep 기록으로 따로 평가 |
| 출력 제한 | 혼합 CAD6 목표각 slew 1.5 rad/s, smoothing 0.35 | 주파수만 높이면 실제 관절이 궤적을 따라가지 못함 |
| 무부하 속도 모델 | hip 약 5.51 rad/s, leg 약 6.54 rad/s | 실제 부하 속도나 연속 토크를 의미하지 않음 |
| 토크 모델 | stall의 75%: hip 약 0.691 N·m, leg 약 1.397 N·m | derating·PD gain·마찰·관성은 식별 전 시뮬레이션 가정 |
| 질량 가정 | CAD 1.792339 kg + L2 0.230 kg | 동적 지지 시 다리당 하중·충격 증가 |
| 정책/관측 | 18 absolute-angle action, 140 observation | phase·duty를 넣을 경우 관측 계약과 체크포인트 변경 |
| 기존 참조 보행 | `onshape_cad6_gait.py`의 wave 및 duty 0.55 tripod 혼합 | legacy 참조 경로이며 현재 직접각 정책에는 사용하지 않음 |

위 값의 근거 코드는 `spider_navigation_env_cfg.py`, `joint_angle_env_cfg.py`,
`joint_angle_control.py`, `robot_actuators.py`, `servo_specs.py`다.
MG996R 제조사는 4.8 V에서 9.4 kgf·cm와 0.19 s/60°를 명시한다. 같은 페이지의
하단 표에는 0.17 s도 있어 저장소는 상단 0.19 s를 보수적으로 사용한다.
RC920DMG 값은 판매자 기반 잠정값이고 실측 검증되지 않았다.
[TowerPro 제조사 사양](https://towerpro.com.tw/product/mg996r/)

정현파 관절각 `q = q0 + A sin(2πft)`는 `2πfA ≤ 1.5 rad/s`를 만족해야 한다.
예를 들어 전체 왕복 폭 30°라면 A=15°이므로 f≤약 0.91 Hz다. 이는 slew만 고려한
상한이며 smoothing, 토크, 지면 부하와 추종 오차까지 고려하면 여유가 더 필요하다.
50 Hz로 명령한다고 서보가 50 Hz 보행을 할 수 있는 것은 아니다.

미끄럼 없는 지지 구간의 발 이동 폭을 S, duty factor를 β, 주파수를 f라 정의하면
평균 속도는 대략 `v ≈ S f / β`로 검토할 수 있다. 예를 들어 S=0.08 m,
f=0.8 Hz, β=0.55면 약 0.116 m/s다. 같은 조건에서 0.20 m/s를 내려면
약 0.138 m의 지지 구간 이동 폭이 필요하다. 실제 CAD의 도달 가능 영역과
충돌·관절 한계로 그 폭이 가능한지부터 확인해야 한다. 이 수치는 성능 예측이 아닌
보폭과 관절 속도 요구를 점검하는 기구학적 계산이다.

## Tripod와 동적 안정성의 구분

Tripod는 다리의 위상 관계다. 앞·뒤 한쪽 다리와 반대쪽 가운데 다리를 한 그룹으로
묶어 교대한다. 번호만으로 그룹을 정하지 말고 현재 URDF의 실제 좌우·앞뒤 배치를
확인해야 한다. 기존 참조의 `(0, 3, 0, 3, 0, 3)/6` 위상도 새 말단 지지 자세에서
지지 다각형이 유효한지 다시 확인해야 한다.

β는 한 주기에서 발이 지면을 지지하는 비율이다. 두 그룹이 반 주기 차이로 움직이면
β>0.5에서 두 그룹 지지가 겹치고, β=0.5에서는 이상적인 순간 교대가 된다.
β<0.5이면 두 그룹 모두 떠 있는 구간이 생긴다. 실제 접촉과 명령 phase는 다를 수 있다.
무게중심 투영이 지지 다각형 안에 머무는 저속 tripod는 정적으로 안정할 수 있다.
동적 gait는 관성, 몸통 운동량과 다음 착지를 포함해 안정성을 평가해야 하므로,
tripod 선택이나 접촉 수 감소만으로 동적 보행이 검증되는 것은 아니다.
[원저자 연구: tripod·bipod와 정적/동적 안정성](https://www.nature.com/articles/ncomms14494)

| 비교 대상 | 연구에서 확인된 구조 | 프로젝트에 가져올 부분 |
|---|---|---|
| RHex | 탄성 다리, 다리당 1개 구동기, 연속 회전, clock 기반 tripod | 위상과 지지/회복 속도의 분리. 현 ±90° 직렬 3관절에 회전 궤적을 복사하지 않음 |
| Bruce | series elastic actuator, CPG와 발 좌표 impedance 제어 | 몸통–다리 순응 제어와 주기 조정. 현 위치 서보의 강성·감쇠 실측 없이 동일 성능 가정 불가 |
| SPINDER | 18 DoF, CPG–IK, IMU·말단 스위치, Dynamixel과 200 Hz 명령 | 현 구조와 가까운 단계적 gait 전환·발 좌표 제어. 질량·서보·주기가 달라 속도 직접 비교 불가 |

RHex의 연속회전과 탄성 구조는 현재 CAD6와 다르다.
[RHex 원저자 논문](https://publications.ri.cmu.edu/rhex-a-simple-and-highly-mobile-hexapod-robot)
Bruce는 탄성 구동기와 impedance 제어를 사용한다.
[Bruce 원저자 논문](https://arxiv.org/abs/2011.00523)
SPINDER의 tripod 실측은 약 0.14 m/s, duty 약 0.52이며 wave보다 빨랐다.
이는 약 0.8 kg 기체의 결과로, 약 2.02 kg인 이 프로젝트의 0.20 m/s 달성 보장은 아니다.
[SPINDER 원저자 논문](https://www.nature.com/articles/s41598-026-56856-0)

## 말단 지지 수정이 먼저 필요한 이유

수정 전 혼합 CAD6의 관측·도착 판정은 말단 toe-button을 사용하지만, 몸체 접촉과
미끄럼 비용은 발 부품 전체 hull의 가장 가까운 점도 지지로 인정했다. 이 부품은 tibia
근위부까지 길게 이어져 있으므로, 말단 비트가 꺼져 있어도 근위부로 몸을 지탱하며
전진 보상을 얻을 가능성이 남는다. 기존 무릎 비용은 몸통 하단 기준 및 에피소드 중
위반 시간 비율이어서 지면에 가까운 무릎에 즉시 충분한 비용을 주지 못할 수 있다.

말단 지지·근위부 접촉·무릎 지면 여유를 같은 지형 표면 기준으로 평가해야 한다.
발 전체가 닿았다고 말단 지지로 인정하지 않고, 말단 이외의 충돌은 비용으로 유지한다.
관절·shaft collider를 끄면 물리적으로 바닥을 관통할 수 있으므로 접촉 판정 수정과
구조물 충돌 비활성화를 혼동하면 안 된다. 말단 접촉점 속도는 링크 선속도에
`ω × r`을 더하고, 진동 바닥에서는 바닥 속도를 빼서 계산해야 한다.

현재 ContactSensor는 링크의 합력 이력을 제공한다. 말단이 지면 근처에 있다는 조건을
추가해도 정확한 접촉점이나 말단으로 전달된 하중을 직접 측정한 것은 아니다.
동시 무릎·말단 접촉은 별도 무릎/근위부 기하 조건으로 걸러야 한다. 추후 고속 gait의
충격과 하중 분배까지 검증하려면 collider별 접촉점/힘 계측 또는 별도 말단 센서가 필요하다.

## 단계적 적용과 통과 기준

1. **말단 지지 학습:** 직접각 정책의 수정된 contact/reward 계약으로 평지부터 재학습한다.
   동일 seed·지형·명령 속도·평가 시간의 기준 정책과 비교해 말단 지지율, 무릎 최소 지면
   여유, 비말단 접촉률, 실제 순진행 속도, 낙상·미끄럼·전력·토크/목표각 속도 포화를 기록한다.
   이 변경만으로 속도가 올랐다고 단정하지 않는다.
2. **빠른 tripod 비교:** 별도 실험 task에서 β=0.60부터 시작해 0.55, 0.50으로 줄인다.
   주파수와 보폭은 위 slew 식 및 실제 추종 오차로 제한한다. 접촉 비트로 조기 착지·늦은
   이륙을 확인하고, IMU로 roll/pitch·각속도를 기록한다. phase·이전 gait 명령이 제어
   상태가 된다면 관측에도 포함해 숨은 상태가 생기지 않도록 한다.
3. **동적 구간 실험:** 평지의 다양한 마찰·외란·질량에서 빠른 tripod가 안정적일 때만
   β<0.5 또는 bipod를 검토한다. 관절 부하에서의 속도·실제 토크·지연·백래시·발 탄성·전원
   강하를 식별한 뒤 actuator 모델에 반영한다. 현재 stall의 75% 한도는 연속 정격이 아니다.
4. **계단·험지 전환:** 고속 gait를 전체 코스에 강제하지 않는다. 지형 여유가 작거나
   착지가 지연되면 duty를 높이고 속도를 낮추는 전환을 검증한다. 계단 성공률과 낙상률은
   평지 속도와 별도로 평가한다.

제안하는 최초 평가 게이트는 여러 seed에서 각 60초 이상 정상 상태 구간, 낙상/이탈 0,
기준 대비 순진행 속도 증가, 무릎 접촉 감소다. 그와 함께 지지 구간 말단 미끄럼,
관절 추종 오차·토크 포화·기계적 에너지가 악화되지 않았는지 확인한다. 에너지 비용은
전진 거리당 `∫Σ|τ q̇|dt / distance`로 비교하고, 발이 떠 있는 시간의 순간 접촉 수를
실패 기준으로 사용하지 않는다. 현재 `minimum_support_feet=3`은 **도착 후 안정 유지**
조건이며 매 걸음에 3족 접지를 강제하는 조건이 아니다. 동적 이동을 허용하더라도
목표에서는 정지하고 안정적으로 서도록 이 게이트를 유지할 수 있다.

50 Hz 관측의 4개 물리 substep 합력 이력은 서로 다른 순간의 접촉을 한 번에 보여 줄 수
있다. 실제 duty·동시 접촉 수·비행 시간·충격 최대값은 200 Hz substep별 로그로
평가해야 한다. 수십 초 평균 접촉 수만으로 동적 안정성을 주장하지 않는다.

## 체크포인트와 검증 범위

접촉·보상 의미가 바뀌면 관측 차원이 같아도 기존 정책과 학습 목적이 다르다.
수정된 계약으로 새 학습을 시작하고, 기준 비교에는 원래 계약으로 실행한 기존 정책의
평가 결과를 보관한다. CPG–IK/phase-action 실험은 행동 계약도 달라지므로 별도 신규
학습이 필요하다. 명시적인 가중치 전이 실험을 하더라도 기존 optimizer 상태를 그대로
재개한 동일 실험으로 취급하지 않는다.

이 문서는 저장소 분석과 공개된 원저자 연구를 근거로 한 적용성 검토다. 이 문서 작성
중 Isaac Sim 동적 보행이나 실제 기체의 속도·열·내구성을 측정하지 않았다. 실제 시뮬레이션은
`DEVELOPMENT_REQUIREMENTS.md`의 A 등급 장비에서 4개 환경부터 수행한다.
