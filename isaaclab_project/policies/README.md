# 과거 정책 보관함

이 디렉터리의 MG90S 정책·ONNX·TorchScript·평가 JSON은 과거 실험을 추적하기 위한 원본 기록이다.
대응하는 MG90S task와 실행기는 제거됐으며 현재 등록된 작업으로 실행하거나 재학습할 수 없다.
68/86개 관측과 residual action을 사용하는 과거 정책은 현재 혼합 서보 CAD6의 140개 관측·18개
절대 관절각 출력 계약과 호환되지 않는다. 파일명이나 메타데이터를 바꿔 호환 정책으로 취급하지 않는다.

각 하위 디렉터리의 모터 수치·성능·해시는 당시 실험을 설명하며 현재 하드웨어의 검증 결과가 아니다.
현재 학습·평가는 [절대 관절각 학습 안내](../docs/joint_angle_training.md)를 따른다.
